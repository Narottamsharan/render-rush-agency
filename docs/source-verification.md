## 5. React Bits Background Integration

- **Selected Component:** **Dark Veil** (`https://www.reactbits.dev/backgrounds/dark-veil`)
- **Engine:** Official `ogl` minimal WebGL canvas shader.
- **Palette Alignment:** Calibrated `hueShift: 28` to render deep charcoal `#0D0D10` with fluid burnt-orange/terracotta highlights (`#D96846`).
- **Performance:** `powerPreference: "low-power"`, dynamic Next.js client-side loading, automatic animation pause via `IntersectionObserver`, and static gradient fallback for `prefers-reduced-motion`.
